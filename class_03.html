Step 3: Grammar Calibration (10-12 min)

Grammar Focus: Affirmative, Negative & Wh- Questions (Including Which)

Let's review the matrix of forms for I, you, we, they in the Present Simple:

1. Affirmative (+)

Direct statements:

• I work downtown.

• We prefer this option.

2. Negative (-)

Using "don't":

• I don't like chaos.

• They don't use paper.

3. Wh- Questions (?)

Using Which, What, Where:

• Which option do you choose?

• Where do you live?

Special Focus: The Power of "Which"

Use Which when there is a limited set of options to choose from. Structure: Which + [noun] + do + [subject] + [verb]?

• "Which computer do you prefer?" (The black one or the white one?)

• "Which project do we start?" (Project A or Project B?)

Fossilized Error Guard (Precision Check)
❌ COMMON MISTAKE

"Which you prefer?" (missing helper word 'do')

"I no work on Saturdays." (incorrect negative form)

🟢 CORRECT STRUCTURE

"Which do you prefer?"

"I don't work on Saturdays."

Interactive Grammar Training (4 Challenges)

1. "______ laptop do you want? The Apple or the Dell?" (Specific choice)

2. "I ______ like working on weekends." (Negative statement)

3. "Where ______ you buy your office equipment?" (Question helper)

4. "We ______ new software systems every month." (Affirmative statement)
